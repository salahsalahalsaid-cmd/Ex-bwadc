# موقع شركة مياه الشرب والصرف الصحي (نسخة تجريبية)

موقع كامل مبني بـ **Node.js + Express + EJS + PostgreSQL**، بنفس فكرة موقع
شركة مياه البحيرة (أخبار - مناقصات - خدمات - إحصائيات - شكاوى) + **لوحة
تحكم (Admin)** تقدر تدير بيها كل المحتوى من غير ما تلمس كود.

> ⚠️ ده مشروع تجريبي/نموذج أولي (Starter) جاهز للتشغيل والتطوير، مش نسخة
> طبق الأصل من الموقع الرسمي، ومحتاج مراجعة أمنية قبل أي استخدام رسمي حقيقي.

---

## 1) المتطلبات قبل التشغيل

- [Node.js](https://nodejs.org) نسخة 18 أو أحدث
- [PostgreSQL](https://www.postgresql.org/download/) نسخة 14 أو أحدث (أو استخدم Docker - شرح تحت)
- (اختياري) [Docker](https://www.docker.com/) لو عايز تشغّل قاعدة البيانات بسهولة من غير تثبيت يدوي

---

## 2) التشغيل لأول مرة (خطوة بخطوة)

### أ) تثبيت الحزم

```bash
npm install
```

### ب) تجهيز قاعدة البيانات

**الطريقة الأسهل (Docker):**

```bash
docker compose up -d
```

هيشغّلك قاعدة بيانات PostgreSQL جاهزة على البورت 5432 بنفس البيانات
الموجودة في `docker-compose.yml`.

**أو الطريقة اليدوية (لو عندك PostgreSQL متثبت):**

```sql
CREATE DATABASE bwadc_db;
CREATE USER bwadc_user WITH ENCRYPTED PASSWORD 'change_this_password';
GRANT ALL PRIVILEGES ON DATABASE bwadc_db TO bwadc_user;
```

### ج) إعداد متغيرات البيئة

```bash
cp .env.example .env
```

بعدين افتح ملف `.env` وعدّل القيم (خصوصًا `PGPASSWORD` و `SESSION_SECRET`
و `ADMIN_EMAIL` / `ADMIN_PASSWORD`).

### د) تجهيز جداول قاعدة البيانات

```bash
npm run migrate
```

هيقرأ كل ملفات SQL من `db/migrations/` بالترتيب وينشئ الجداول.

### هـ) زرع بيانات تجريبية (حساب المدير + محتوى مبدئي)

```bash
npm run seed
```

### و) تشغيل الموقع

```bash
npm start
```

الموقع هيشتغل على: `http://localhost:3000`
ولوحة التحكم على: `http://localhost:3000/admin` (بالإيميل والباسورد اللي حطيتهم في `.env`)

للتطوير مع إعادة تشغيل تلقائية عند أي تعديل في الكود:

```bash
npm run dev
```

## 3) إزاي تعمل "أبجريد" (تحديث) للموقع بأمان؟

النظام مبني عشان التحديث يكون بسيط ومضمون، وفيه نوعين من التحديث:

### أ) تحديث الكود نفسه (تصميم / صفحات / مميزات جديدة)

1. اعمل نسخة احتياطية (backup) لقاعدة البيانات قبل أي تحديث:
   ```bash
   pg_dump -U bwadc_user -d bwadc_db -F c -f backup_$(date +%Y%m%d).dump
   ```
2. حمّل/انسخ ملفات الكود الجديدة (أو اعمل `git pull` لو حاطط المشروع على Git).
3. حدّث الحزم لو فيه حزم جديدة:
   ```bash
   npm install
   ```
4. شغّل أي ترقيات جديدة لقاعدة البيانات (لو موجودة - شرحها تحت):
   ```bash
   npm run migrate
   ```
5. أعد تشغيل السيرفر:
   ```bash
   # لو شغّال يدوي
   npm start

   # لو شغّال بـ pm2 (موصى بيه على السيرفر الحقيقي)
   pm2 restart bwadc-website
   ```

### ب) تحديث قاعدة البيانات (إضافة عمود/جدول جديد)

**متلمسش جدول موجود مباشرة يدويًا.** بدل كده:

1. اعمل ملف SQL جديد جوه `db/migrations/` بترقيم أكبر من آخر ملف موجود، مثال:
   ```
   db/migrations/003_add_bill_lookup_table.sql
   ```
2. اكتب فيه أوامر SQL بتاعتك (مثال: `ALTER TABLE ...` أو `CREATE TABLE ...`).
3. شغّل:
   ```bash
   npm run migrate
   ```

نظام الترقيات (`db/migrate.js`) بيحتفظ بسجلّ (جدول `schema_migrations`)
بكل ملف اتنفذ قبل كده، فمش هيكرره تاني، ولو حصل خطأ في أي ملف هيعمل
Rollback تلقائي ليه بس من غير ما يأثر على الملفات اللي قبله. يعني تقدر
تعمل `npm run migrate` براحتك في أي وقت وهو هيطبّق بس الجديد.

> 💡 مثال جاهز موجود في `db/migrations/002_example_add_news_views_counter.sql`
> يوضحلك الأسلوب.

## 4) هيكل المشروع

```
bwadc-website/
├── db/
│   ├── migrations/       # كل تعديلات قاعدة البيانات مرقّمة بالترتيب
│   ├── migrate.js        # سكريبت تشغيل الترقيات (npm run migrate)
│   └── seed.js           # بيانات تجريبية أولية (npm run seed)
├── public/
│   ├── css/style.css     # كل تنسيقات الموقع
│   └── uploads/          # صور الأخبار المرفوعة من لوحة التحكم
├── src/
│   ├── db.js             # الاتصال بقاعدة البيانات
│   ├── server.js         # نقطة تشغيل السيرفر
│   ├── middleware/auth.js
│   └── routes/
│       ├── public.js     # صفحات الموقع للزوار
│       └── admin.js      # لوحة التحكم (CRUD كامل)
├── views/                # قوالب EJS (الصفحات)
│   └── admin/            # صفحات لوحة التحكم
├── .env.example
├── docker-compose.yml
└── package.json
```

## 5) الأقسام اللي تقدر تديرها من لوحة التحكم

| القسم | الوصف |
|---|---|
| الأخبار | إضافة/تعديل/حذف/نشر أو إخفاء أي خبر مع صورة غلاف |
| المناقصات | إضافة/تعديل/حذف المناقصات مع تاريخ جلسة الفتح والتأمين |
| الخدمات | إدارة "أهم الخدمات" اللي تظهر في الصفحة الرئيسية |
| الإحصائيات | الأرقام اللي تظهر في قسم "إحصائيات وأرقام" |
| الشكاوى | متابعة شكاوى ومقترحات الزوار وتغيير حالتها |
| إعدادات الموقع | اسم الشركة، أرقام التليفونات، الخط الساخن، السوشيال ميديا...الخ |

## 6) قبل ما تنشر الموقع فعليًا (نصائح أمان مهمة)

- غيّر `SESSION_SECRET` و `ADMIN_PASSWORD` في `.env` لقيم قوية وغير افتراضية.
- شغّل الموقع خلف HTTPS (مثلاً عبر Nginx كـ reverse proxy أو Cloudflare).
- خلّي `NODE_ENV=production` في السيرفر الحقيقي.
- اعمل نسخ احتياطية دورية لقاعدة البيانات (`pg_dump`).
- استخدم أداة زي [pm2](https://pm2.keymetrics.io/) لتشغيل السيرفر في الخلفية
  وإعادة تشغيله تلقائيًا لو حصل له كراش:
  ```bash
  npm install -g pm2
  pm2 start src/server.js --name bwadc-website
  pm2 save
  ```
